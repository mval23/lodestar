# Logo working files

These are construction-accurate working files for the Axes & Fix mark, built on a 16-unit grid. They are not final artwork: the wordmark still needs to be redrawn, and the app icon layers need to be checked against Apple's Human Interface Guidelines. See `../BRAND.md` §4.

| File | Use |
|---|---|
| `symbol.svg` | Two-color symbol on light grounds (ink axes, `#1F4BFF` fix) |
| `symbol-on-dark.svg` | On dark grounds (`#EEECE7` axes, `#6F8BFF` fix) |
| `symbol-mono.svg` | One color |
| `favicon.svg` | 16 px pixel-snapped; switches colors automatically in dark mode |
| `app-icon-light.svg` / `app-icon-dark.svg` | 1024 px square tiles. Leave them unmasked: each platform applies its own corner mask. |
